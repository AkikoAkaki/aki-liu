# 项目优化与重构变更日志 (2026-05-20)

本项目于 2026-05-20 执行了一次针对系统仪表盘（Observability Dashboard）的视觉设计精致化、行内代码排版规范化以及交互动画体验的深度打磨升级。以下为具体修改细节。

## 1. 仪表盘性能指标着色系统更新

### 问题背景
* 仪表盘的原生黄色与红色对于极简且现代的书卷报刊（Editorial）风视觉语境而言略显生硬（偏向强原色高亮），需要调整至更温和且和谐的高级配色系统。

### 修改方案
* **文件变更**：`assets/css/dashboard.css`
* **重置状态色值**：
  - 将中度警告黄色 `--dash-warn` 更新为柔和高级的 `#f0bf00`（原黄色为 `#f59e0b`），配套的卡片半透明着色背景调整为 `rgba(240, 191, 0, 0.14)`。
  - 将高度警告红色 `--dash-bad` 更新为清透淡雅的桃粉红 `#e88b95`（原红色为 `#ef4444`），配套的卡片半透明着色背景调整为 `rgba(232, 139, 149, 0.14)`。
  - 移除了卡片、趋势图与环形图上生硬的高亮色块，以这套高阶色彩代之，视觉过渡更加浑然天成。

## 2. 全站行内代码样式规范化与等宽字体统一

### 问题背景
* 仪表盘及部分模块原有的行内代码（如 `hugo --gc`）直接使用了底色完全透明的无边框排版，或夹杂了杂乱的内联重置样式，不仅缺乏排版统一性，而且不易阅读；此外行内代码应当采用更具科技感的高清等宽字体进行标示。

### 修改方案
* **行内代码风格提纯**：修改 `assets/css/base.css`，定义全局行内 `code` 元素样式，完全看齐主流精致文章的排版规格：
  - **字体大小**：`0.85em`
  - **背景色**：`var(--color-bg-muted)`（深色模式下为柔和纯黑，浅色下为温和淡灰）
  - **间距与圆角**：上下 `0.2rem`，左右 `0.4rem`，并配置 `6px` 的小圆角。
  - **文本前景色**：显式配置为 `color: inherit`，强制行内代码块与其外部容器的文本层级和颜色保持绝对一致，解决在次要文字中代码块颜色突兀或主次不分的问题。
* **代码块格式隔离**：在 `base.css` 中为 `pre code` 级联选择器部署样式清空逻辑，确保正式的高亮多行代码块不会错误地继承行内代码的圆角与背景噪声。
* **统一渲染等宽字体**：全局等宽字体声明 `code, pre, kbd, samp` 统一定制为 `"JetBrains Mono", monospace`，极大提升了排版精细度与工业美感。
* **页面硬编码清理**：修改 `layouts/dashboard/single.html`，剔除了在 `hugo --gc` 和 `partialCached` 等页面代码元素上的所有硬编码内联样式，统一交由全局 CSS 进行更清爽的规则委托渲染。

## 3. 趋势图（Trend Chart）高保真插值缓动交互升级

### 问题背景
* 在之前的版本中，移动鼠标检验趋势图节点时，游标标线、气泡工具提示（Tooltip）以及内部显示的数值均是瞬间生硬跳跃的，缺乏一种流线型的高阶交互动态品质。

### 修改方案
* **文件变更**：`layouts/dashboard/single.html`、`assets/css/dashboard.css`
* **双重属性插值（Dual-Lerp）缓动**：
  - 引入 `requestAnimationFrame` 驱动的平滑插值（`lerp`）运动循环，设置了 `0.18` 的黄金阻尼物理运动系数。
  - 完美地将 **坐标位置**（`cx`, `cy`, `tx`, `ty`）与 **数据数值**（`curVal`）一同进行插值缓动。
  - **效果**：气泡和游标不再“闪现”到新节点，而是顺滑地滑行过去。更令人惊叹的是，气泡中包含的 Latency 编译耗时数值（如 `870ms`）也会以极其流利、飞速变换的形式数字滚变到新数值（如从 `870ms` 滚变到 `810ms`），具有极强的动效保真度。
* **动态状态颜色过渡**：
  - 游标的活跃点（Active Dot）描边颜色在滑行时会实时根据 `curVal` 插值重新计算，使圆点在滑过不同级别的耗时区间时，能够无比平滑地蜕变颜色。
* **渐进淡入淡出（Opacity Fade）机制**：
  - 在 `assets/css/dashboard.css` 中为 `#chart-cursor` 部署快速淡入淡出过渡 `transition: opacity 0.14s cubic-bezier(0.4, 0, 0.2, 1)`。
  - 将游标出现与消失的逻辑从生硬的 `display: none` 修改为基于 CSS 类名的 `.classList.add/remove('active')` 委托。
  - **效果**：当鼠标离开趋势图时，气泡与线条不是瞬间消失，而是以一个极速、极富弹性感的淡出动画滑入空气中；当鼠标进入时快速淡入，交互充满高级空气感。
* **高性能边界闭环**：
  - 设置高精度数值收敛防线（`dist < 0.05`），一旦滑动到达目的地便会自动休眠重绘帧循环，规避冗余的 CPU 硬件渲染损耗。
